# NEXUS 无人机高精度目标定位项目

本仓库用于管理“UWB + 外部多相机视觉 + ROS2 融合定位”项目的代码、实验数据、工程记录和答辩材料。

## 从哪里开始

1. 先读 [项目索引](docs/PROJECT_INDEX.md)，它规定事实来源和文档阅读顺序。
2. 再读 [实施规划书](<docs/无人机高精度目标定位项目规划 (2).md>) 和 [模块选型图](<docs/module-map (1).html>)。
3. 开发代码放在 `code/`，实验按 `experiments/` 记录，答辩交付物放在 `defense/`。

## 当前状态

仓库目前处于“规划与脚手架”阶段，尚未承诺任何算法精度或硬件已联调。实测数据、预测结果和外部参考资料必须分开标记，未经实验记录支持的结论不得写入最终答辩材料。

## 目录速览

```text
code/        ROS2 工作空间、算法脚本和评估工具
data/        原始/中间/处理后数据及元数据
docs/        规划、架构、决策、实验与协作文档
experiments/ 可复现实验定义、运行记录和结果索引
outputs/     生成的图表、表格、报告和演示导出物
defense/     PPT、技术报告、视频、海报和问答材料
templates/   可复制的记录与报告模板
```

协作规则见根目录 [AGENTS.md](AGENTS.md) 和 [CLAUDE.md](CLAUDE.md)。
