# 答辩材料

答辩材料只引用已登记在 `docs/records/evidence-index.md` 的证据。规划目标、仿真结果、实测结果和外部参考必须在页脚或备注中明确区分。

## 目录

- `slides/`：PPT 源文件和导出 PDF，命名 `defense_slides_v01.*`
- `report/`：技术报告源文件和 PDF，命名 `technical_report_v01.*`
- `qa/`：评委问答、证据链接和演示故障预案
- `demo/`：演示脚本、录屏索引和现场检查单
- `poster/`：海报源文件和导出物

## 推荐叙事顺序

问题与场景 → 系统架构 → 坐标/时间同步 → 算法对比 → 融合与降级 → 实测验证 → 演示 → 分工与风险。

每次材料更新在 `records/` 留一条发布记录，注明来源运行编号和版本号。
