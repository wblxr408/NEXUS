# E012 metrics

These files are the machine-readable snapshot copied from
`outputs/carla_uwb_reproduction/` for run
`2026-08-29_E012_carla_uwb_sandbox_v29`.

- `observations.csv`: 400 algorithm-facing 3D range rows;
- `ground_truth.csv`: 100 independent CARLA UAV transform rows;
- `estimates.csv`: 600 rows across six algorithm routes;
- `metrics.json`: per-route validity, 3D error, timing, and provenance.

The values are generated simulation/test-sample data. They must not be cited
as physical UWB measurements or as a final accuracy result.
