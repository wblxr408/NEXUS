# 步骤 10：端到端应用与可视化

- 日期：2026-08-20
- 类型：执行指导
- 状态：draft
- 对应总计划：步骤 10
- 关联设计：`docs/architecture/2026-08-19_design_demo_dashboard_information_architecture.md`
- 本文范围：组织采集、计算、评估和展示；不在网页层实现定位算法。

## 先给结论

端到端应用的核心不是“页面漂亮”，而是让观众清楚看到目标在哪里、数据来自哪里、数据是否新鲜、误差如何验证。在线运行和离线回放必须使用同一语义，硬件失败时仍能展示可追溯结果。

## 一、定义展示层级

### 主视图

回答“目标现在在哪里”：

- `map` 轴、单位和范围；
- 外部目标位置和短轨迹；
- 当前来源模式；
- 数据年龄和有效性；
- 可选的真值点或验证点。

### 状态视图

回答“链路是否正常”：

- UWB、视觉、bridge、融合状态；
- 首帧时间、最后采样时间；
- 丢帧、过期和重连；
- 当前配置和运行编号。

### 证据视图

回答“结果是否可信”：

- 当前运行编号；
- 误差曲线和统计；
- 样本数、单位和异常规则；
- 标定版本和真值方法。

### 标定辅助视图

只在调试或答辩解释时展示 `map`、相机、UWB 基站、目标轴和检测点，不应把它和普通实时主屏混成一团。

## 二、端到端链路顺序

```text
设备/回放数据
  ↓
ROS1 硬件层或 ROS2 输入
  ↓
契约校验和时间状态
  ↓
坐标转换
  ↓
目标观测/融合
  ↓
记录与评估
  ↓
RViz2/Dashboard
```

每个阶段都要有可观察状态，不能只在最终页面看到一个坐标而无法判断中间哪一层失败。

## 三、RViz2 组织建议

至少区分：

- `map` 坐标轴；
- 无人机平台状态；
- UWB 原始或转换观测；
- 视觉观测；
- 融合目标；
- 真值/测试点。

图例、颜色和名称必须表明对象和来源。平台轨迹不能用“目标轨迹”标题，原始观测不能和融合输出画成同一种线。

## 四、Dashboard 信息设计

主屏建议显示：

- 目标 ID；
- x/y/z 和单位 m；
- 来源模式；
- 置信度或协方差摘要；
- 数据年龄；
- 连接状态；
- 当前运行编号。

无数据显示“无数据”，过期显示“过期”，不要显示 0 或保留上一帧但不标状态。

## 五、在线和回放两条路径

### 在线路径

从真实 ROS1/ROS2 数据开始，适合展示实时链路和状态切换。

### 回放路径

读取已登记的 rosbag、日志或导出数据，适合验证图表和应急演示。回放数据必须保留原始采样时间、运行编号和配置来源，不能重新标成“实时”。

## 六、可直接借用的方案

- ROS2 RViz2；
- rosbridge_suite 或 ros2 bag 作为浏览器数据出口；
- 现有 Dashboard 的主地图、状态卡片、事件和标定视图；
- 模块图中“网页自己写，通信层不重复造协议”的边界。

## 七、必须自行确定的内容

- 目标与平台的视觉层级；
- 来源模式和误差的表达；
- 在线/回放切换方式；
- 无效、过期、断桥告警文案；
- 演示要显示的验证点；
- 哪些数据可以进入主屏。

## 八、事件和状态记录

每条事件建议包含：

```text
timestamp_ns:
receive_timestamp_ns:
component: uwb / vision / bridge / fusion / dashboard
level: INFO / WARN / ERROR
event_type: first_frame / stale / switch / recovery / drop
target_id:
run_id:
description:
```

网页只展示事件，不替代 ROS2/离线侧的状态判定。

## 九、产出物

- 端到端流程图；
- RViz2 图层和图例规范；
- Dashboard 主视图、状态视图、证据视图设计；
- 在线/回放说明；
- 数据状态和告警字典；
- 演示用运行编号列表。

## 十、通过与停止条件

### 通过条件

- 在线和回放使用相同字段语义；
- 页面能区分平台、目标、观测和融合；
- 无数据和过期状态不会显示成有效坐标；
- 可从页面追溯运行编号、配置和来源；
- 新成员能按说明完成一次展示。

### 停止条件

- 网页自行计算定位或融合；
- 在线和回放使用不同坐标/单位；
- 页面只显示最终坐标，没有来源和数据年龄；
- 图表无样本数、单位或运行编号；
- 标定和真值可被网页随意修改。

## 十一、禁止越界

- 不用视觉特效掩盖数据无效；
- 不把展示刷新频率当作传感器更新频率；
- 不把网页中的 0 当作真实坐标；
- 不在实时主图混淆平台轨迹和目标轨迹。
