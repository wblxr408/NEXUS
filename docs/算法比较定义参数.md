

首先必须分开两个真值对象：

- 无人机自身：`map → base_link`
- 沙盘目标：`map → target_link`
- 视觉中间结果：`camera_i → target_link`

不能把无人机平台真值当成沙盘目标真值。

## 一、两类算法共同使用的核心指标

| 指标 | 含义 | 适用对象 |
|---|---|---|
| 3D Position RMSE | 三维位置误差的均方根，反映总体定位精度 | 无人机、目标 |
| 3D Position MAE | 三维位置误差平均值，受异常值影响小于 RMSE | 无人机、目标 |
| P50 / Median Error | 误差中位数，表示典型样本水平 | 无人机、目标 |
| P95 Error | 95% 样本误差不超过的值，反映尾部风险 | 无人机、目标 |
| Maximum Error | 最大误差，用于发现严重失效 | 无人机、目标 |
| Axis Bias | x、y、z 各方向的平均误差，发现系统性偏差 | 无人机、目标 |
| Availability / Success Rate | 有效输出样本数 ÷ 应输出样本数 | 无人机、目标 |
| Failure Rate | 无效、丢失、拒绝或失锁的比例 | 无人机、目标 |
| Update Rate | 实际输出频率，例如 Hz | 无人机、目标 |
| Latency | 从传感器采样到算法输出的延迟，建议报告平均值和 P95 | 无人机、目标 |
| Recovery Time | 失锁或无效后恢复有效输出所需时间 | 无人机、目标 |
| Runtime | 单帧或单次解算耗时 | 无人机、目标 |
| CPU/GPU/Memory | 算法运行资源消耗 | 无人机、目标 |

位置误差定义为：

\[
e_i = \hat{p}_i-p_i^{gt}
\]

\[
d_i=\|e_i\|_2
\]

\[
RMSE=\sqrt{\frac{1}{N}\sum_i d_i^2}
\]

建议所有算法至少报告：

```text
position_rmse_3d_m
position_mae_3d_m
position_p50_3d_m
position_p95_3d_m
position_max_3d_m
availability
update_rate_hz
latency_mean_ms
latency_p95_ms
recovery_time_ms
```

注意：`CEP50/CEP95` 严格来说通常指二维水平面误差，不是三维误差。当前仓库里的 `position_metrics()` 使用三维距离却命名为 `cep50/cep95`，后续最好改成：

```text
position_p50_3d_m
position_p95_3d_m
horizontal_cep50_m
horizontal_cep95_m
```

## 二、无人机自身定位指标

无人机自身主要评价 `map → base_link`。

### 1. 平台位置误差

建议同时报告：

- 三维位置 RMSE
- 水平位置 RMSE：只计算 x/y
- 高度 MAE 或 RMSE
- x/y/z 轴向偏差
- P50、P95

这样可以区分“平面定位好但高度差”与“整体三维都不好”。

### 2. 平台姿态误差

如果算法输出姿态，建议使用旋转矩阵的 geodesic rotation error：

\[
e_R =
\cos^{-1}\left(
\frac{\operatorname{trace}(R_{gt}^{-1}\hat{R})-1}{2}
\right)
\]

单位为度。

建议报告：

```text
rotation_mean_deg
rotation_rmse_deg
rotation_p50_deg
rotation_p95_deg
```

如果只关心飞行水平稳定性，也可以单独报告：

```text
roll_error_deg
pitch_error_deg
yaw_error_deg
```

但主指标最好使用整体旋转误差，避免欧拉角万向节锁和角度范围问题。

### 3. 轨迹指标

对于静态点，位置 RMSE 已经足够；对于平移、绕目标、升降等动态轨迹，建议加入：

- ATE：Absolute Trajectory Error，绝对轨迹误差
- RPE：Relative Pose Error，相对位姿误差

ATE 衡量估计轨迹与真值轨迹在绝对坐标中的偏差；RPE 衡量一段时间间隔内的相对运动是否正确。

这两个指标来自经典 TUM RGB-D SLAM benchmark：

> Sturm et al., “A Benchmark for the Evaluation of RGB-D SLAM Systems”, IROS 2012.

对于本项目，如果 `map` 已经通过实测标定固定，建议不做自由的 SE(3) 对齐后再报告结果；否则会掩盖坐标系、外参或尺度错误。若某个算法天然没有绝对坐标，只能对齐时，必须明确写出对齐方式。

### 4. UWB 专用诊断指标

这些不是所有算法都必须有，但对 UWB 很重要：

| 指标 | 含义 |
|---|---|
| Range Residual RMSE | 估计位置反算距离与实际测距之间的残差 |
| Range Residual P95 | 测距残差尾部误差 |
| NLOS Outlier Rate | 非视距异常测量比例 |
| Packet Loss Rate | UWB 测距或定位数据丢包率 |
| GDOP | 基站几何布局对定位可观测性的影响 |

GDOP 不是算法精度本身，而是几何条件指标。应作为实验条件或诊断结果报告，不能把低 GDOP 直接说成算法精度高。

## 三、无人机定位沙盘目标的指标

目标定位要评价完整的 `map → target_link`，同时建议保留中间的 `camera_i → target_link` 结果。

### 1. 目标平移误差

与无人机一样，使用：

```text
translation_rmse_3d_m
translation_mae_3d_m
translation_p50_3d_m
translation_p95_3d_m
translation_max_3d_m
```

但应分别报告：

```text
camera_to_target_error
map_to_target_error
```

这样可以区分：

- 视觉算法本身误差；
- 无人机平台定位误差；
- 相机外参和坐标转换误差；
- 最终端到端目标误差。

### 2. 目标旋转误差

对于 6D 位姿算法，报告：

```text
rotation_rmse_deg
rotation_p50_deg
rotation_p95_deg
```

如果目标具有对称性，例如圆柱、储罐或对称建筑，普通旋转误差可能不公平。需要使用对称性最小化后的旋转误差，或者使用 ADD-S。

### 3. ADD / ADD-S

这是 6D 物体姿态论文中非常常见的指标。

普通物体：

$
ADD =
\frac{1}{|M|}
\sum_{x\in M}
\left\|
(\hat{R}x+\hat{t})-(R_{gt}x+t_{gt})
\right\|
$

其中 $M$ 是目标三维模型点集。

对于对称物体：

$
ADD\text{-}S =
\frac{1}{|M|}
\sum_{x_1\in M}
\min_{x_2\in M}
\left\|
(\hat{R}x_1+\hat{t})-(R_{gt}x_2+t_{gt})
\right\|
$

含义是：估计姿态变换后的目标模型，与真值模型之间的平均三维表面距离。

常见报告方式：

```text
ADD_mean_m
ADD_p95_m
ADD-S_mean_m
ADD-S_p95_m
recall_at_10_percent_diameter
```

ADD/ADD-S 被 PVNet、GDR-Net 以及 BOP 6D 目标姿态评测广泛使用。

相关参考：

- Hinterstoisser et al., “Model Based Training, Detection and Pose Estimation of Texture-Less 3D Objects in Heavily Cluttered Scenes”, ACCV 2012.
- Peng et al., “PVNet: Pixel-wise Voting Network for 6DoF Pose Estimation”, CVPR 2019.
- Wang et al., “GDR-Net: Geometry-Guided Direct Regression Network for 6D Object Pose Estimation”, ICCV 2021.
- Hodan et al., “BOP: Benchmark for 6D Object Pose Estimation”, ECCV 2018.

### 4. 2D 投影误差

将目标模型关键点或表面点投影到图像，比较估计投影和真值投影的像素误差。

建议报告：

```text
projection_error_mean_px
projection_error_p95_px
projection_success_rate
```

该指标对视觉算法特别有用，因为它能判断“姿态是否能解释图像”，即使三维误差暂时较大，也能发现相机内参、匹配或 PnP 的问题。

### 5. 重投影误差

对于基于关键点、特征匹配或 PnP 的方法，报告：

```text
reprojection_error_mean_px
reprojection_error_p95_px
```

它属于观测一致性指标，不等同于真实世界定位误差。重投影误差小，并不一定说明 `map → target_link` 的米制位置准确，因为外参、尺度和坐标系仍可能错误。

## 四、视觉算法还应报告的诊断指标

| 指标 | 含义 |
|---|---|
| Detection Recall | 目标被检测或识别出的比例 |
| Matching Inlier Ratio | 特征匹配中通过几何验证的内点比例 |
| Inlier Count | 有效匹配点数量 |
| Occlusion-wise Recall | 不同遮挡程度下的成功率 |
| Distance-wise Recall | 近、中、远距离下的成功率 |
| Lighting-wise Recall | 不同光照条件下的成功率 |
| Confidence Calibration | 置信度是否与真实成功概率一致 |

这些指标不能替代位置误差，但可以解释算法为什么失败。

## 五、不确定性指标

如果算法输出协方差，建议增加：

- NEES：Normalized Estimation Error Squared
- NIS：Normalized Innovation Squared
- Coverage Probability：置信区间覆盖率
- NLL：Negative Log-Likelihood

NEES 用来检查“算法给出的协方差是否可信”。例如算法经常输出很小的协方差，但实际误差很大，则说明它过度自信。

这对 UWB、视觉和融合算法都适用，但前提是算法必须输出有明确含义的协方差。没有协方差的算法不要伪造该指标。

## 七、最重要的比较规则

1. 所有算法必须使用同一批输入、同一份真值和同一时间对齐规则。
2. 不允许用另一种算法补齐当前算法的无效帧。
3. 无效帧必须计入可用率损失。
4. 静态、动态、遮挡、低照、UWB NLOS 等场景必须分开统计。
5. 不能只报告平均误差，至少同时报告 RMSE、P50、P95、可用率和延迟。
6. 论文中的精度数字只能作为参考，最终结果必须来自 `experiments/runs/`。
7. 对称目标使用 ADD-S 或 BOP 的对称性处理，不能直接用普通 ADD。
8. `CEP95` 仅用于明确的二维水平误差；三维误差使用 `3D P95` 或 `3D RMSE`。

仓库目前已经有位置误差、可用率、频率、延迟和重投影误差的基础评估代码；后续比较完整 6D 目标姿态时，还需要补充旋转误差、ATE/RPE、ADD/ADD-S 和不确定性一致性指标。
