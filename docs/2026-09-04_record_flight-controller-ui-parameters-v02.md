# 飞控界面与 UWB 参数记录 v02

本记录来源于用户在 2026-09-04 提供的五张飞控参数界面照片。用户明确要求将照片显示的标签 ID `1.0` 修正为项目实际使用的 `2.0`；其余可见数值按照片转录。完整机器可读记录位于 `code/deployment/raspberry_pi_readonly_stack/config/hardware_user_v02.yaml`。

四个 UWB 基站坐标是用户确认的现场测量标定值，按厂商界面以厘米记录，同时换算为米供 ROS2 入口使用：基站 1 `(90,-90,256)`，基站 2 `(0,500,271)`，基站 3 `(400,500,271)`，基站 4 `(400,0,271)`；坐标偏航角为 `9°`，标签 ID 为 `2`，标签总数为 `1`。用户确认这些数值就是本场地采用的标定与精度依据；未另行提供数值形式的测量不确定度，因此配置不虚构标准差或置信区间。

PID、速度、高度、油门、电源、光流、GNSS 补偿和串口波特率均是界面值的只读档案。由于尚未取得厂商参数键和全部工程单位，NEXUS 不对这些值作单位推断，也不会把它们写回飞控。无人机的速度、高度、解锁、模式和任务仍完全由原飞控链路管理。

该配置状态为 `user_confirmed_field_measured`，其中 UWB 基站坐标标记为 `measured`。UWB 标签到 `base_link` 的外参、IMU 噪声及相机标定属于其他独立标定项，不改变本记录中基站坐标已经现场测量的事实。
