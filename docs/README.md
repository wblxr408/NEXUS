本题目面向无人机系统定位算法，采用**UWB和视觉方式**，对目标进行**高精度定位**。主要内容包括：

（1）安装ROS2操作系统；

（2）对已有定位算法进行精度比较，确定精度为厘米级的定位算法；

（3）对获得的目标位置坐标进行转换；

（4）完成演示应用。
