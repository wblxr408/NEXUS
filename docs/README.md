本题目面向无人机系统定位算法，采用**UWB和视觉方式**，对目标进行**高精度定位**。主要内容包括：

（1）安装 Ubuntu 22.04 + ROS2 Humble 作为项目自研主线；同时准备 Ubuntu 20.04 + ROS1 Noetic 和幻思官方 `fcu_core` 兼容环境；

（2）对已有定位算法进行精度比较，确定精度为厘米级的定位算法；

（3）对获得的目标位置坐标进行转换；

（4）完成演示应用。

## 已确认的赛题对象

- 被定位对象是**无人机之外的目标**；无人机作为传感器、通信和计算平台。
- 幻思官方 ROS1/`fcu_core` 负责硬件兼容，赛题要求的视觉、目标定位、坐标转换、评估和演示在 ROS2 中二次开发。
- ROS1 与 ROS2 之间建立显式信息通道；除非演示需要目标跟踪控制，否则 ROS2 结果不必回传飞控。
- 当前硬件尚未到货，视觉输入、目标/UWB 标签安装、坐标系和真值测量保持 TBD，后续由项目自定义并用实验固定。
- 最终验收以 PPT 和有实验来源的演示视频为主，不要求现场实时飞行。

范围决定见 [ADR-002](decisions/2026-08-18_ADR-002_target-localization-scope.md)。旧规划中把目标位姿等同于无人机位姿或默认通过 `motion_001` 回传飞控的表述，按该决定降为条件性方案。
