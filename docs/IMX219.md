IMX219 是一款应用广泛的 800 万像素图像传感器，常被用于树莓派 Camera V2 模块及各类相机模组中。其核心参数如下：

### 📷 IMX219 核心参数

| 参数类别   | 具体参数     | 典型值/规格                    |
| :--------- | :----------- | :----------------------------- |
| **传感器** | 型号         | Sony IMX219                    |
|            | 有效像素     | 约 808 万像素                  |
|            | 感光尺寸     | 1/4 英寸                       |
|            | 像素尺寸     | 1.12µm × 1.12µm                |
|            | 快门类型     | 卷帘快门 (Rolling Shutter)     |
| **图像**   | 最大分辨率   | 3280 × 2464                    |
|            | 静态图像     | 最高支持 3280 × 2464 分辨率    |
|            | 视频支持     | 1080p @ 30fps, 720p @ 60fps 等 |
| **镜头**   | 视场角 (FOV) | **79.3°** (常见型号)           |
|            | 光圈 (F)     | **F2.0**                       |
|            | 焦距         | **2.85mm**                     |
| **物理**   | 模组尺寸     | 25mm × 24mm                    |
|            | 接口         | MIPI CSI-2                     |
|            | 固定孔       | 4个螺孔，用于固定              |

### 💡 补充说明

- **帧率表现**：帧率会随分辨率变化。例如，在 3280×2464 全分辨率下约为 **21fps**，在 1920×1080 下可达 **30fps**，在 1280×720 下可达 **60fps**。
- **版本差异**：不同厂商的模组在视场角（如 77°、79.3°、120°、160°）、光圈、是否有红外滤光片等方面可能存在差异，具体参数需以产品说明为准。
- **应用场景**：该传感器常用于人脸识别、道路标识识别、车牌识别等 AI 视觉应用。
