# 目标米制几何及不确定性接口

本记录对应D01/D04的数值层。ROS2像素身份轨迹至本接口的在线对应点生产与平台采样时刻对齐尚未完成，不代表目标三维主链已打通。

## 已知三维关键点

`nexus_vision_localization.reference_geometry.solve_keypoint_pose(object_points_m, image_points_px, K, D)` 接受目标坐标系下已知米制Nx3点及其一一对应的Nx2图像点。目标原点由三维几何定义；检测框大小和无尺度参考纹理不能自行生成这些米制点。

- 与固定Tag/多Tag板共用几何求解：RANSAC、平面多解检查、四点非平面AP3P、正深度、重投影内点重分类、内点率和几何可观测性检查。
- 输出 `transform_camera_reference`（本接口reference即target）、6×6协方差、重投影RMSE、内点率/数量和原输入对应点的 `inlier_indices`。Tag板包装接口额外返回实际保留的tag_ids。
- 协方差顺序为 `[相机坐标平移, 目标坐标右乘旋转扰动]`，单位m/rad；它由内点像素噪声和投影Jacobian计算，条件于所给模型尺寸/内参，不能代表未知模型误差。
- 默认像素sigma=1、RANSAC阈值3px、内点率≥0.6、重投影RMSE≤3px；运行时必须结合真实标定数据确认，当前是显式算法配置。

## map目标位姿与协方差

`target_geometry.compose_target_pose(T_map_body, T_body_camera, T_camera_target, P_body, P_extrinsic, P_relative, joint_covariance=None)` 计算完整位姿链。所有位姿必须对应图像采样时刻，调用者不能以接收时刻的最新平台位姿替换。

输入误差约定：

| 输入 | 平移误差 | 旋转误差 |
|---|---|---|
| 平台 | map轴 | map固定轴左乘（ROS Odometry） |
| 外参 | body轴 | camera轴右乘 |
| 目标相对观测 | camera轴 | target轴右乘 |

输出为map平移和map固定轴旋转的6×6 ROS协方差，包括平移—旋转交叉项。平台角度误差及外参角度误差均通过目标距离传播到位置不确定性，不再仅旋转视觉位置协方差。

默认三个输入误差相互独立；存在相关性时，提供同顺序18×18联合协方差，必须与三个边缘块一致且半正定。函数不会猜测跨源相关性；共享图像/标定/历史窗口造成的相关性仍需在联合后端中建模。
