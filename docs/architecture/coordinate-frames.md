# 坐标系约定（草案）

状态：坐标语义已由 ADR-005 冻结；物理原点、外参和设备轴向待现场测量确认。

| frame | 含义 | 原点/方向 | 来源 |
|---|---|---|---|
| `map` | 沙盘/任务世界坐标系 | 右手系，`+z` 向上；物理原点和 `+x/+y` 基准待确认 | 标定记录 |
| `world` | 外部视觉或分析使用的世界别名 | 与 `map` 的关系先固定 | 坐标决策记录 |
| `uwb_anchor_i` | 第 i 个 UWB 基站 | 基站实测坐标 | 硬件测量 |
| `camera_i` | 第 i 台相机的驱动/`CameraInfo` 光学 frame | 相机标定结果；不凭名称猜轴向 | 标定运行 |
| `base_link` | 无人机机体/飞行平台 | 机体参考点 | 飞控/视觉标定 |
| `target_link` | 被定位的外部目标 | 目标参考点，待定义 | 目标规格/标定记录 |
| `tag_target` | 目标上的视觉标记 | 标签中心；与 `target_link` 的外参待标定 | 视觉检测 |

ROS1 `fcu_core` 使用 `tf`，ROS2 算法侧使用 `tf2`；信息通道不自动猜测轴向。未知厂商 UWB 坐标一律记为 `uwb_raw`，只允许 ROS1 适配层在单位和轴向已确认后转换为 `map`。若 UWB 直接测量目标，必须记录 UWB 标签到 `target_link` 的外参；若 UWB 只测量无人机，则目标世界坐标通过 `map → base_link → camera_i → target_link` 求得。两种模型不得混用。矩阵、物理轴向、时间同步方式和外参版本必须在首次正式标定前填定，并关联一个实验运行编号。
