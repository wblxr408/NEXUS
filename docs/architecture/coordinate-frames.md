# 坐标系约定（草案）

状态：`TBD / 待现场测量确认`

| frame | 含义 | 原点/方向 | 来源 |
|---|---|---|---|
| `map` | 沙盘/任务世界坐标系 | 待团队用物理基准点确认 | 标定记录 |
| `world` | 外部视觉或分析使用的世界别名 | 与 `map` 的关系先固定 | 坐标决策记录 |
| `uwb_anchor_i` | 第 i 个 UWB 基站 | 基站实测坐标 | 硬件测量 |
| `camera_i` | 第 i 台相机 | 相机标定结果 | 标定运行 |
| `base_link` | 无人机机体 | 机体参考点 | 飞控/视觉标定 |
| `tag_target` | 标签/目标点 | 标签中心 | 视觉检测 |

ROS1 `fcu_core` 使用 `tf`，ROS2 算法侧使用 `tf2`；bridge 不自动猜测轴向。幻思视觉回传涉及 NED/机体系转换；矩阵、轴向、右手系、单位、时间同步方式和外参版本必须在首次正式标定前填定，并关联一个实验运行编号。
