## 六、参数可获取性结论

**✅ 公开可得**：飞控处理器 / 传感器类型 / 接口 / 安全机制；UWB 标称精度；GNSS 完整规格（和芯星通官方手册）。

**❌ 官网查不到、需额外获取（重点）**：

1. **Mcontroller V7 具体传感器型号**（如 IMU 芯片型号）——官网仅描述「三轴加速度计」等，未给具体芯片。
2. **机载相机详细参数**——相机型号、物理接口、真实分辨率、帧率、内参 K/畸变 D、采样时间戳、快门类型均未确认；内参需自行标定，其余需问厂商或首次联调验收。
3. **UWB 实际精度 / 刷新率 / 通信距离**——仅标称 < 10cm，实测值需硬件到货后自行实验测定（这也是答辩中最有价值的真实数据）。
