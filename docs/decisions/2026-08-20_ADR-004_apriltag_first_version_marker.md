# ADR-004：首版视觉标记采用 AprilTag 36h11

- 日期：2026-08-20
- 状态：accepted
- 负责人：项目组
- 关联任务/运行：步骤 01、05、06；首个 E001 运行待创建

## 背景

首版视觉链路需要在不预设相机型号、图像接口、标签实际尺寸或外参的前提下，冻结一种可检测、可由 ROS2 上游节点直接使用的标记方案。此前视觉准备保留 AprilTag/ArUco 两种候选，导致标签打印、接口和目标语义不能统一。

## 候选方案

1. 继续保留 AprilTag 与 ArUco 双方案。
2. 首版采用 AprilTag 36h11，并用已固定版本的 `apriltag_ros` 做检测；ArUco 仅保留为非首版备选。

## 决定

1. 首版标记固定为 **AprilTag family `36h11`**，首个目标预留 tag ID `0`，对应项目目标 ID `target_0`。
2. 检测节点使用第三方 `apriltag_ros`，输入是同一采样时刻的矫正图像与 `CameraInfo`，输出是检测消息/TF；项目自有 `nexus_vision_localization` 只在后续作为语义适配层，将已确认的检测结果转为 `TargetObservation`。不修改上游检测源码。
3. `target_link` 固定定义为**外部目标刚性标记安装板外向平面的几何中心**。安装板必须刚性固定到目标、平整且不反光，并保留可复测的中心/朝向基准；AprilTag 印刷中心相对于该点的三维外参必须在装配后实测并版本化，不能假设为零。
4. 标签边长、相机型号、相机数量、安装板实际尺寸、`camera_i` 外参与 `tag_target → target_link` 数值保持 `TBD`，只允许由硬件到货后的可见距离、分辨率和标定运行确定。禁止从本 ADR 或上游示例配置复制一个尺寸作为真实值。

## 为什么这样选

`apriltag_ros` 已提供 ROS2 检测、姿态、检测质量和 TF 输出，能避免项目重复实现标签检测协议。`36h11` 是上游明确支持的标签族；单一首版方案能统一打印、目标 ID、配置和首日视觉验收。空间坐标与精度仍取决于真实相机、内参和外参，不由标签族本身保证。

## 验证计划与结果

到货前完成：参数、目标 ID、安装板参考点和无观测规则已记录；完整 ROS2 构建须包含 `apriltag_ros`。

到货后必须完成：原始 Image/CameraInfo/时间戳确认；实体标签边长复测；一次检测日志；安装板外参测量；相机内外参标定。只有这些证据齐全后，`target_0` 的 AprilTag 观测才可进入世界坐标求解或 E001。

## 影响、回滚和后续动作

- 文档、配置和演示首版统一称为 AprilTag 36h11；不再把 ArUco 写成首版主链路。
- 相机或标记条件不满足时，视觉状态必须为无有效观测，不能回退为 ArUco 而不新增决策记录。
- 若更换标签族、目标 ID 语义或安装参考点，新增 ADR 并重新标定相关外参。
