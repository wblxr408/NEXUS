# ADR-020 用户接受近似标定的实机启动链

状态：已实现；实机运行待恢复供电。用户授权：“近似标定就够了，然后我需要你打通四个环节”。

统一入口新增 allow_approximate_calibration，并将显式 experimental_approximation 及非空 approximations 传到平台、视觉运动和目标几何加载器。默认 measured/test 的入口行为保持；不将近似配置改写为 measured，不放宽单位、旋转矩阵或图像内参检查。

专用 live_approximate_localization.launch.py 使用已有 Pi ROS 飞控桥接，转发 /imu_global_001 到 /nexus/fcu/imu，保留桥接已完成的单位、轴向和时间戳转换。相机入口使用 E028 内参和既有相机 TCP/时钟通道。该入口不重复打开飞控串口、不启动另一 MAVLink 读取器。

固定视觉参考改为可选；该实机入口默认不要求 AprilTag。近似初始位姿来自静置 200 组稳健测距窗口和最近 200 个连续 IMU 样本：测距拟合 tag 位置，减去配置的机体杠杆臂；重力给出俯仰/侧倾，初始 yaw 使用显式先验。用户确认的 9° 坐标偏置保留，但初始机头绝对朝向仍是假设，配置明确说明。当前相机朝下换轴与共点平移模型也是近似，不是实测外参。

200 组均值用于静置初始化和网页显示。运动后平台估计仍用当前原始距离及已有稳健优化；不把约 200 秒历史平均重新打当前时间戳加入逐帧定位。拒绝仅重映射平滑输出到原始观测入口，因为时间语义和协方差不相同。新话题 /nexus/uwb/startup_statistics 与 /nexus/platform/initialization_status 加入录包清单。

目标链保持参考图注册、特征身份跟踪、多视角目标几何、目标融合与网页/RViz 输出。基线不足或输入过期仍输出未定位状态，不能用地图登记坐标假装识别得到的坐标。

本地消息链路、真实 GPU 推理在合成图像上的坐标输出、完整启动证据见 E045。用户已确认无人机没电，因此相机服务自启动模板尚未安装到 Pi，实机联合验收不属于本地通过结论。
