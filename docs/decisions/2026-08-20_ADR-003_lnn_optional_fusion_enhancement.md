# ADR-003：将液态神经网络限定为可选融合增强方案

- 日期：2026-08-20
- 状态：accepted
- 负责人：项目组
- 关联任务/运行：步骤 7～9 的单源基线、融合、动态与失效实验；正式运行编号待定

## 背景

项目主线是 FanciSwarm 官方 UWB 基线与视觉目标观测在 ROS2 中的定位、评估和展示。当前没有已登记的真实硬件、标定和真值数据；因此不能把任何学习模型的预期效果表述成定位精度结论。

液态神经网络（Liquid Neural Network，LNN）具有时序建模能力，可用于研究观测质量随运动、遮挡或 NLOS 条件变化的规律。但它需要可追溯的训练数据，并会降低第一版融合的可解释性。飞控已有 EKF 和实时控制闭环不属于本决策的可替换范围。

## 候选方案

1. 只使用冻结参数的固定协方差加权融合。
2. 在单源基线完成后，按实测残差增加可解释的轻量自适应权重或 EKF/UKF。
3. 在方案 1 的基线上，以 LNN 做时序质量评估或残差修正的离线/ROS2 对比实验。

## 决定

1. 第一版主链路维持固定协方差融合与显式降级策略；在完成单源基线前，不训练、部署或宣传 LNN。
2. LNN 可以作为方案 3 的可选增强和答辩算法对比项，但不得替换 Mcontroller 的 EKF、实时飞控控制或 ROS1 官方 `fcu_core`。
3. LNN 的优先输出是视觉/UWB 观测的质量权重、残差修正、有效性或不确定度；不直接无约束地产生最终目标坐标。最终输出仍由 ROS2 `nexus_fusion_localization` 发布为 `/nexus/target/pose`，并保留固定融合/最佳单源回退。
4. 训练输入只能来自已登记运行中的目标观测、协方差/检测置信度、采样与接收时间、观测年龄、重投影误差或 UWB 残差、来源与遮挡状态。飞行平台状态仅在测量模型和坐标转换已确认时作为辅助量，绝不能被误标成目标位置。
5. 模型必须是因果的，只使用当前及历史观测；训练、验证和测试按独立运行/场景划分，禁止同一运行的相邻帧同时出现在训练集与测试集。模型代码版本、权重、特征定义、训练配置和数据校验信息必须写入运行记录。
6. 在实际在线接入前，先离线回放验证；在线推理超过预设延迟、输入过期、输出无效或质量低时，立刻回退到固定融合、最佳单源或“无有效定位”状态。

## 为什么这样选

LNN 的价值在于对时间相关的遮挡、NLOS 和观测质量变化建模，而不是取代已能解释和复现的几何定位链路。先形成官方 UWB、单相机/多相机视觉和固定融合的共同时间栅格基线，才能判断学习模型是否真实改进，而不是只让轨迹看起来更平滑。

## 验证计划与结果

尚无结果。仅在以下条件全部满足后启动 LNN 对比：

1. E001 完成，目标、坐标、时间、真值和单源指标均可追溯。
2. 已有覆盖正常、动态及遮挡/NLOS 的独立已登记运行，可形成不泄漏的训练、验证和测试集。
3. 在同一测试运行、同一时间栅格和相同有效性规则下，与固定融合和最佳可用单源比较 3D RMSE、P50/P95、最大误差、可用率、恢复时间及端到端延迟。

只有核心区误差有统计上可解释的降低、可用率不下降、延迟满足演示要求且失效回退正确时，才可把 LNN 作为主融合候选。否则保留固定融合或最佳单源，并将 LNN 记录为未达标的对比结果。

## 影响、回滚和后续动作

- 当前不下载、不实现、不接入任何 LNN 框架或模型；待真实数据和接口条件满足后再选择开源实现，并登记版本和许可证。
- LNN 相关代码只能位于 ROS2 融合/离线分析范围，不进入 ROS1 `fcu_core` 源码。
- 回滚方式为禁用 LNN 输出，恢复冻结的固定协方差融合或最佳单源；无需改变飞控。
- 若未来要把 LNN 输出回传 `motion_001`，必须新增单独的飞控安全与接口 ADR，不能由本决策自动授权。
