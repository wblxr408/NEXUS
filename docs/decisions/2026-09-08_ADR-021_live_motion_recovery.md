# ADR-021 运动中的只读定位初始化与恢复

2026-09-08，用户要求 IMU 修复、实时输出及选取目标到坐标显示全链路，并明确不能在识别期间持续静止，当前以手持模拟飞行验证。

采用既有飞控桥接的实时姿态与当前 UWB 测距做近似初始化；不再将运动后的恢复绑定到 200 组静置窗口。200 组异常剔除和均值保留为独立统计。零偏使用本次已测静置先验，不从转动窗口估计。飞控姿态只读转发与时间对齐，9° 地图偏置保留，位置仍由项目测距求解。IMU 间断或外部约束超期后显式重新初始化，所需数据必须新鲜且单位、坐标系匹配。

未采用忽略时间异常、无限积分、把统计均值冒充瞬时距离或直接采信飞控位置的做法，因为它们会掩盖真实输入和坐标问题。

相机使用数组批量填充 ROS 数据，修复逐字节赋值造成的延迟；已选目标保留基础特征预算，背景估计仍可自适应减算。均未改变相机标定分辨率或放宽 stale 阈值。
