# ADR-007：双对象迭代定位与机载视觉/UWB 测量模型

- 日期：2026-08-24
- 状态：accepted
- 负责人：项目组
- 关联任务：UWB 基线、机载视觉、坐标转换、融合、标定与演示
- 依据：`docs/figures/参数.png`、2026-08-24 老师答复
- 与既有 ADR 的关系：本 ADR 对 ADR-002 第 1 条及“保留的两种测量模型”中关于定位对象范围和测量模型的部分具有优先级；ADR-002 其余 ROS 分层、输出语义和证据边界继续有效。

## 背景

`docs/figures/参数.png` 的规格表列出“摄像头像素 800W像素”与“UWB 定位：支持（需配 4 个 UWB 基站）”。老师进一步明确：无人机自带摄像头；UWB 用于替换沙盘四周相机；高精度定位必须同时实现无人机自身和无人机之外物体的定位，并让两类结果迭代。沙盘和无人机均为共享设备，使用时间由老师分配。

此前 ADR-002 将无人机限定为传感器/计算平台，并在“目标直接测量”和“平台间接测量”之间保留选择。该边界不再完整反映已确认的双对象要求。

## 候选方案

1. 只定位无人机自身，使用 UWB 或飞控输出作为最终结果。
2. 只定位无人机之外的目标，依赖沙盘四周固定相机或为目标另配 UWB 标签。
3. UWB 定位无人机自身，机载摄像头定位机外目标；通过已标定的无人机位姿、相机外参和统一 `map` 坐标系把两类观测迭代为机外目标世界坐标。

## 决定

1. 采用候选方案 3。无人机自身位置和无人机之外物体的位置都是本项目的定位对象；二者分别使用 `base_link` 和 `target_link` 表达，禁止以其中之一冒充另一对象。
2. 4 基站 UWB 是无人机自身的绝对位置来源，并替换沙盘四周相机。UWB 标签随无人机时，UWB 输出只能解释为无人机位置，不得直接标为机外目标位置。
3. 无人机自带 800 万像素摄像头是首版视觉输入，负责观测机外目标；沙盘四周相机不纳入主链路。规格图只确认设备存在，原始图像帧、`CameraInfo`、时间戳、快门、驱动和相机 frame 必须在首次联调验收后才能作为已验证接口使用。
4. 机外目标世界坐标按平台间接测量链计算：UWB/飞控给出采样时刻的无人机位姿，机载视觉给出目标相对相机的观测，经 `base_link → camera` 外参与统一 `map` 转换得到 `target_link`。具体坐标轴、时间同步阈值和外参数值继续由 ADR-005、ADR-006 与后续标定运行约束。
5. “两者都必须实现”是演示和实验主链路要求，不是精度结论。UWB、视觉、坐标变换和迭代/融合必须在同一可追溯运行中分别记录；没有真值和正式运行数据，不得宣称厘米级或其他精度达标。
6. 沙盘和无人机须按老师分配的时段使用。每次采集记录必须写明时段、设备布置与外参版本；若 UWB 基站或相机安装位姿无法跨时段保持，重新检查或重做相应标定，不把旧外参静默沿用。

## 验证计划与结果

目前只有规格资料与老师答复，尚无硬件联调、标定或精度实验结果。首次联调和后续运行至少验证：

1. UWB 输出的标签对象、坐标系、单位、时间戳和更新率；
2. 机载摄像头的原始图像、`CameraInfo`、时间戳、光学 frame 与 ROS 接入；
3. 无人机位姿与视觉观测按采样时间匹配，能够产生明确来源的 `map → target_link` 结果；
4. 每次预约时段中的 UWB 基站和相机外参可追溯，并有独立真值方案后再报告精度。

## 影响与后续动作

- 不再将沙盘四周相机列为主链路资源、采购替代方案或视觉输入假设。
- 视觉接口验收、机载相机标定和 `base_link → camera` 外参成为主线前置条件；无需为机外目标追加 UWB 标签作为首版方案。
- 实验应先建立无人机自身 UWB 基线和机外目标机载视觉基线，再做时间对齐、坐标转换与迭代/融合对比。
- 设备预约是实验配置的一部分；不可用时段不阻塞离线接口、仿真或回放工作，但不得伪造为实测结果。
