# 架构决策记录（ADR）

文件名：`YYYY-MM-DD_ADR-<三位编号>_<slug>.md`。

复制 `templates/adr.md`，填写状态（`proposed / accepted / superseded / rejected`）、背景、候选方案、决定、验证和影响。
