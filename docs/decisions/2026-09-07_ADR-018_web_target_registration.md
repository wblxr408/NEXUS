# ADR-018：当前定位网页与人工目标注册

日期：2026-09-07。授权：用户要求将现有网页适配当前输入输出，承接框选和指定具体目标的需求。

- 保留双对象快照、历史位置、条件协方差语义；默认不连接旧 CARLA，也不根据网络连接臆测仿真模式。
- 点击定格时临时订阅去畸变原图，收到一帧后退订。保留像素和 header，框和参考点换算到原图坐标；不从 JPEG 预览还原注册参考。
- 重组 rosbridge 图像分片；使用 BigInt 计算纳秒时间并编码为 JSON 整数，避免 JS Number 舍入。
- 仅确认时发布参考图像与注册请求，后端确认才认定成功，目标维持 static。
- 参考图像改为可靠 QoS：原尽力传输订阅在一次性大图传输中出现配对超时，可靠观察者已收到同一原图；改为可靠订阅后成功与拒绝注册路径通过。实时视频 QoS 不变。
- 发布权限只放行两个精确话题；已安装 rosbridge 的 glob 解析器只剥除单引号，因此配置使用单引号列表。测试使用实际解析器，并用无害隔离话题验证拒绝。
- 输入收包状态与定位有效性分开；无来源的指标保持未知。飞控及其他算法优化不由本次修改。

未选独立 HTTP 注册网关：已有 ROS 协议足够，无需新增依赖。未选持续原图预览：定格时读取原图可以减少持续传输开销。

验证和当前工作区回归限制见 E027；相机采集仍暂停。
