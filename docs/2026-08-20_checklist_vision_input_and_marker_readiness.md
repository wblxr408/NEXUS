# 视觉输入与目标标记准备清单

- 日期：2026-08-20
- 类型：checklist
- 状态：pre_hardware_ready
- 关联：`nexus_vision_localization`、`apriltag_ros`、步骤 01、05、06

首版固定使用单相机 **AprilTag 36h11** 和 `apriltag_ros` 的接口与记录方式，不预设实际相机、标签实际尺寸或相机外参。标签检测成功不等于已完成目标世界定位。决定见 `ADR-004`。

## 必须在硬件到货后冻结的规格

| 字段 | 当前值 | 冻结证据 |
|---|---|---|
| `target_id` | `target_0` | 目标照片与运行记录 |
| `target_link` 物理参考点 | 刚性安装板外向平面的几何中心 | 尺寸图与测量记录 |

| 主相机 `camera_i` | TBD | 相机接口、内参和 frame 记录 |
| 图像采样时间来源 | TBD | 相机/驱动证据 |

## 到货后操作顺序

1. 制作或选择一个刚性、平整、非反光的安装板，标出其外向平面几何中心为 `target_link`；标签拆装即要求复测外参。
2. 以预计最近/最远相机距离拍摄原始帧，确定 AprilTag `36h11` 的实体边长，记录每次的检测距离、视角、光照和是否成功；不从规划数字倒推“必须达到”的标签尺寸。
3. 先取得该相机的 `Image`、`CameraInfo`、frame 与时间戳，再将它接入 `apriltag_ros`。
4. 相机内参完成后，用单相机 PnP 输出相机坐标下的观测；`map` 变换必须等待独立外参标定。
5. 只有两路以上相机同时满足原始帧、时间、内参与固定外参条件，才填写 `caliscope` 启用记录。

## 预定义的无观测行为

视觉模块无图像、无 `CameraInfo`、无时间戳或无标签时，必须发布/记录无效原因和最后有效采样时刻；不得生成零坐标、上一帧坐标或融合坐标。本清单与 `code/analysis/test_samples/` 的功能样例共同作为到货前验收依据。
