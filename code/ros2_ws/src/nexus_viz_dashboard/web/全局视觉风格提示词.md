# NEXUS — Industrial Telemetry Console

## High-Fidelity Web Dashboard Visual Design Prompt

Design a high-fidelity 16:9 desktop web dashboard for **NEXUS**, an external-target localization and sensor-fusion system used in an indoor drone test arena.

The provided hand-drawn reference establishes the INFORMATION ARCHITECTURE and spatial composition. Preserve its major layout and information hierarchy, but completely refine the visual language.

This is NOT a SaaS dashboard, NOT a generic AI dashboard, NOT a PowerPoint slide, NOT a cyberpunk cockpit, and NOT a futuristic military HUD.

The visual identity should combine:

**industrial instrumentation + experimental laboratory equipment + aerospace telemetry + weathered engineering interface + rough analog measurement devices + controlled material noise.**

The overall impression should be:

> **“A sophisticated scientific instrument that has been used inside a harsh industrial research environment for years.”**

It should feel engineered, physical, technical, slightly weathered, and intellectually serious.

---

# 1. BRAND IDENTITY — NEXUS

The product name is:

**NEXUS**

Treat NEXUS as a real engineering instrument brand, not merely a page title.

Place a compact **NEXUS identity mark** in the upper-left region of the dashboard.

The wordmark should use an unusual industrial display typeface rather than a generic sans-serif.

The NEXUS wordmark should feel inspired by:

* industrial stencil lettering
* aerospace equipment labels
* old scientific instruments
* railway / machinery identification plates
* technical drafting typography
* experimental laboratory equipment
* brutalist editorial typography

The wordmark may use slightly condensed, angular, mechanically cut letterforms.

The letters should have subtle imperfections or mechanical character, but remain highly legible.

Recommended visual treatment:

**NEXUS**

* uppercase
* condensed display lettering
* approximately 22–26 px
* letter spacing: 0.08–0.14em
* dark charcoal / graphite
* optionally accompanied by a tiny serial mark such as:
  `NEXUS // LOC-01`
  or
  `NEXUS / TARGET LOCALIZATION SYSTEM`

Do NOT make the NEXUS logo futuristic, glowing, chrome, metallic, or 3D.

It should look like a **screen-printed equipment label**.

# 2. TYPOGRAPHY SYSTEM

Typography is a major part of the visual identity.

Do NOT use a generic default web font everywhere.

Use a three-layer typography system.

### A. NEXUS display / branding font

Use an industrial or condensed display typeface with strong geometric or stencil characteristics.

Possible references:

* DIN Condensed
* Bahnschrift Condensed
* Oswald
* Bebas Neue
* Rajdhani
* Archivo Narrow
* IBM Plex Sans Condensed
* Trade Gothic Condensed
* Eurostile Extended / Condensed-inspired industrial lettering

For the actual visual design, prefer a **custom-looking condensed industrial display style** rather than simply rendering a normal sans-serif.

NEXUS should have a distinct typographic personality.

### B. Interface typography

Use:

**Inter / IBM Plex Sans / Noto Sans SC**

Recommended:

* Chinese UI: Noto Sans SC
* English UI: IBM Plex Sans or Inter
* Section labels: IBM Plex Sans SemiBold
* Body text: Noto Sans SC / IBM Plex Sans Regular

### C. Numerical / telemetry typography

Use:

**IBM Plex Mono / JetBrains Mono**

All measurements, timestamps, coordinates, frame IDs, run IDs, latency values, and experimental metrics should use a monospaced numerical face.

Examples:

`X 12.50 m`

`Y 08.30 m`

`Z 01.20 m`

`AGE 0.10 s`

`RUN E123`

`RMSE 0.12 m`

Numerical values must use tabular numerals so changing values do not visually shift the layout.

# 6. INDUSTRIAL WASTELAND MATERIAL LANGUAGE

The industrial-wasteland character must NOT become a literal post-apocalyptic scene.

Do not add:

* rust everywhere
* broken machinery
* destroyed buildings
* dirt-covered screens
* dramatic smoke
* flames
* military weapons
* dystopian scenery

Instead, express the atmosphere through subtle material cues.

Use:

* fine paper grain
* photocopy-like micro-noise
* slightly uneven ink density
* very subtle gray speckling
* faint technical drawing marks
* tiny registration marks
* measurement ticks
* serial numbers
* stencil fragments
* calibration marks
* worn-looking divider lines
* small mechanical reference symbols
* subtle edge abrasion
* imperfect print-like texture

The interface should feel as if it was printed, measured, stamped, scanned, and repeatedly used.

The texture should be extremely subtle.

Approximate visual intensity:

**5–8%**

It must never reduce readability.
