GLOBAL PRESENTATION VISUAL SYSTEM PROMPT
============================================================
PROJECT VISUAL IDENTITY:
PRECISION AERIAL LOCALIZATION
UWB × VISION × ROS2

DESIGN DIRECTION:
HIGH-IMPACT PRECISION ENGINEERING
× AEROSPACE NAVIGATION
× SCIENTIFIC VISUALIZATION
× EDITORIAL MINIMALISM
============================================================


[0. MASTER DESIGN INTENT]

Create a visually exceptional academic engineering presentation for a UAV high-precision target localization system based on UWB + Vision sensor fusion and ROS2.

The presentation must NOT look like:

- a generic university project PPT
- a conventional blue “technology” template
- a startup pitch deck
- an AI-generated presentation
- a software architecture brochure
- a generic drone advertisement
- a cyberpunk interface
- a gaming HUD
- a futuristic sci-fi poster

Instead, it should feel like:

“A precision aerospace navigation system being presented by a serious robotics research team.”

The design language should combine:

Aerospace navigation
+
Precision instrumentation
+
Robotics
+
Computer vision
+
Spatial computing
+
Scientific measurement
+
Experimental engineering
+
Premium editorial typography

The desired emotional progression is:

FIRST IMPRESSION:
“Powerful.”

SECOND IMPRESSION:
“Technically sophisticated.”

THIRD IMPRESSION:
“This system is actually engineered and measurable.”

The visual philosophy is:

PRECISION BEFORE DECORATION.
EVIDENCE BEFORE EFFECTS.
GEOMETRY BEFORE ICONS.
TYPOGRAPHY BEFORE GRAPHICS.
SPATIAL DEPTH BEFORE GRADIENTS.
RESTRAINT AFTER IMPACT.

The deck should be visually bold, but never visually noisy.

============================================================
[62. FINAL QUALITY CHECK]
============================================================

Before finalizing any slide, verify:

1. Is there one dominant visual idea?
2. Is the title visually strong enough?
3. Is typography sufficiently bold?
4. Is there enough scale contrast?
5. Is the background contributing to the concept?
6. Is every graphic semantically meaningful?
7. Are UWB and Vision colors consistent?
8. Is uncertainty represented geometrically?
9. Is the visual hierarchy obvious from 2 meters away?
10. Does the slide still work if body text is removed?
11. Does the slide belong to the same visual world as the previous slide?
12. Does it look like scientific engineering rather than generic technology?
13. Is the slide visually impressive without becoming noisy?
14. Are there any fake technical details?
15. Are target metrics clearly distinguished from measured results?

If any answer is NO, revise the slide.
